# 소원커피라벨

소원커피 원두 라벨(1125×750, 3:2 가로형)을 웹에서 바로 편집하고 **PNG 이미지로 저장**하거나 **인쇄/PDF 저장**할 수 있는 웹앱입니다.
링크에 접속하기만 하면 누구나 설치 없이 사용할 수 있습니다.

## 사용 방법

1. 왼쪽 **라벨 편집** 탭에서 원두 정보(이름, 산지, 품종, 가공, 고도, 컵노트, 로스팅 날짜 등)를 입력합니다.
2. 오른쪽 미리보기를 확인합니다. 클릭하면 크게 볼 수 있습니다.
3. **이미지 저장 (PNG)** 또는 **인쇄 / PDF 저장**을 누릅니다.
4. 자주 쓰는 라벨은 **리스트에 저장**해 두고 **저장 목록** 탭에서 다시 불러옵니다.

> 저장 목록은 지금 쓰고 있는 브라우저 안에만 보관됩니다. 다른 컴퓨터로 옮기거나 다른 사람과 나누려면 **백업 추출** → **백업 가져오기**를 사용하세요.

## 개발

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # dist/ 에 배포용 파일 생성
```

`main` 브랜치에 푸시하면 GitHub Actions가 자동으로 빌드해 GitHub Pages에 배포합니다.
